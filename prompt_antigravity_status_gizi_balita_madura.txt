2. DATA (WAJIB DIPAKAI APA ADANYA)
--------------------------------------------------------------------------------
File : data_status_gizi_balita.xlsx (di root proyek), sheet pertama "data gizi balita".
Sheet kedua "Keterangan" hanya penjelasan, abaikan saat training.
Kolom (urutan tetap), 2.300 baris, tanpa duplikat/kosong:
  kabupaten                 : Bangkalan | Sampang | Pamekasan | Sumenep      (kategorikal)
  jenis_kelamin             : Laki-laki | Perempuan                          (kategorikal)
  umur_bulan                : 6-59                                           (numerik)
  berat_badan_kg            : ~3.5-24                                        (numerik)
  tinggi_badan_cm           : ~57-120 (panjang/tinggi badan)                 (numerik)
  zscore_tb_u               : z-score tinggi badan menurut umur              (numerik)
  zscore_bb_u               : z-score berat badan menurut umur               (numerik)
  asi_eksklusif             : Ya | Tidak                                     (kategorikal)
  sanitasi_layak            : Ya | Tidak                                     (kategorikal)
  pendapatan_keluarga_juta  : juta rupiah/bulan, 0.5-9                       (numerik)
  lama_sekolah_ibu          : 6 | 9 | 12 | 16 (SD/SMP/SMA/PT)                (numerik)
  episode_infeksi_3bln      : 0-3 (diare/ISPA 3 bulan terakhir)              (numerik)
  status_gizi               : TARGET. Normal | Stunting | Gizi Kurang
Komposisi kelas: Normal 900, Stunting 850, Gizi Kurang 550.
Definisi label pada data: Stunting = z TB/U < -2; Gizi Kurang = z BB/U < -2 dengan TB/U tidak
pendek; selain itu Normal. (Definisi sederhana untuk keperluan SPK; bukan klasifikasi lengkap
Permenkes.) Rujukan umum untuk teks: WHO Child Growth Standards 2006 dan Permenkes No. 2 Tahun 2020
tentang Standar Antropometri Anak (sebut sebagai rujukan, jangan mengarang nomor halaman/tautan).
JANGAN membuat ulang/mengganti data ini. Jika file tidak ditemukan, app menampilkan pesan ramah
+ uploader, bukan crash.
CATATAN KEJUJURAN: data SIMULASI (sintetis), bukan data anak sebenarnya, tanpa identitas.
Tampilkan catatan ini di Manajemen Dataset dan Tentang & Panduan.

TABEL ACUAN Z-SCORE (WAJIB dipakai persis, ini yang dipakai saat membangun kolom z-score di data).
Interpolasi linear dengan numpy.interp pada titik umur (bulan) [0, 6, 12, 24, 36, 48, 60]:
  TINGGI median Laki-laki : [49.9, 67.6, 75.7, 87.1, 96.1, 103.3, 110.0]
  TINGGI median Perempuan : [49.1, 65.7, 74.0, 85.7, 95.1, 102.7, 109.4]
  TINGGI SD Laki-laki     : [1.9, 2.15, 2.35, 3.05, 3.7, 4.2, 4.4]
  TINGGI SD Perempuan     : [1.9, 2.25, 2.55, 2.85, 3.85, 4.3, 4.75]
  BERAT median Laki-laki  : [3.3, 7.9, 9.6, 12.2, 14.3, 16.3, 18.3]
  BERAT median Perempuan  : [3.2, 7.3, 8.9, 11.5, 13.9, 16.1, 18.2]
  BERAT SD = median_berat x fraksi, fraksi (kedua jenis kelamin) pada titik umur yang sama:
             [0.12, 0.12, 0.12, 0.125, 0.13, 0.135, 0.14]
Rumus:
  zscore_tb_u = (tinggi_badan_cm - median_tinggi(umur, jk)) / sd_tinggi(umur, jk)
  zscore_bb_u = (berat_badan_kg - median_berat) / (median_berat x fraksi(umur))
Ini perkiraan interpolasi dari kurva WHO, bukan tabel resmi lengkap; tulis kejujuran ini di
Tentang & Panduan. Hasilnya harus cocok dengan kolom z-score di data (selisih maksimum <= 0.01
karena pembulatan 2 desimal) - buktikan di check_all.py.
Di app, pengguna cukup mengisi umur, jenis kelamin, berat, tinggi; z-score DIHITUNG OTOMATIS
dengan rumus di atas lalu ditampilkan.

4. MODEL KNN, SELEKSI FITUR & FILE .joblib
--------------------------------------------------------------------------------
TEMUAN PENTING dari uji awal data ini (jadikan acuan; buktikan ulang sendiri):
  - Memakai SEMUA kolom (termasuk one-hot kategorikal) membuat akurasi KNN hanya ~70% karena
    fitur kurang relevan mengganggu jarak.
  - Memakai fitur z-score saja (zscore_tb_u, zscore_bb_u) memberi akurasi ~90% (K ~9).
  - Fitur numerik terpilih memberi ~87%.
Karena itu pipeline WAJIB mendukung SET FITUR yang dapat dipilih dan dipilih otomatis lewat CV:
  SET A "Z-score inti"      : zscore_tb_u, zscore_bb_u
  SET B "Numerik lengkap"   : umur_bulan, berat_badan_kg, tinggi_badan_cm, zscore_tb_u, zscore_bb_u,
                              pendapatan_keluarga_juta, lama_sekolah_ibu, episode_infeksi_3bln
  SET C "Semua fitur"       : SET B + one-hot (kabupaten, jenis_kelamin, asi_eksklusif, sanitasi_layak)
train_model.py (bisa dijalankan mandiri: python train_model.py, dan diimpor app.py):
  - Baca xlsx, validasi kolom/tipe, buang baris kosong/duplikat.
  - Pipeline: ColumnTransformer(numerik -> StandardScaler, kategorikal -> OneHotEncoder(
    handle_unknown="ignore", sparse_output=False)) -> KNeighborsClassifier. Untuk SET A/B tanpa
    kategorikal, gunakan hanya bagian numerik.
  - Split stratified 80/20, random_state=42.
  - Grid dengan 5-fold StratifiedKFold CV: set fitur {A,B,C} x K = 1..25 x metrik {euclidean, manhattan}
    x weights {uniform, distance}. Pilih kombinasi akurasi CV tertinggi (seri -> K lebih kecil,
    set fitur lebih sederhana). Bandingkan juga macro-F1.
  - Latih ulang pada data latih, hitung akurasi/precision/recall/F1 (data uji), simpan:
      models/knn_gizi_balita_madura.joblib berisi dict:
        {"pipeline": <Pipeline>, "feature_set": "A|B|C", "features": [...],
         "k": int, "metric": str, "weights": str, "classes": list,
         "metrics": {...}, "n_train": int, "n_test": int, "trained_at": ISO-datetime,
         "sklearn_version": str, "data_file": str}
  - Cetak ringkasan hasil di terminal. Target: akurasi uji terbaik >= 0.85.
app.py:
  - Muat joblib dengan st.cache_resource. Jika file belum ada ATAU gagal dimuat (mis. beda versi
    scikit-learn di server), otomatis latih ulang & simpan lalu lanjut tanpa crash
    (notifikasi kecil "Model dilatih ulang otomatis").
  - Tombol "Latih Ulang & Simpan Model (.joblib)" dan "Unduh model .joblib" (st.download_button)
    di halaman Evaluasi & Optimasi K. Setelah latih ulang: kosongkan cache dan rerun.
  - Info model aktif: set fitur, K, metrik, weights, akurasi, tanggal latih, versi sklearn.
  - Saat prediksi, bentuk baris input lengkap (termasuk z-score hasil hitung), lalu ambil kolom
    sesuai "features" model aktif. Faktor risiko yang tidak dipakai model (mis. ASI, sanitasi pada
    SET A) tetap ditampilkan sebagai panel "Faktor Risiko Tambahan" (informatif, bukan input KNN),
    dengan keterangan jujur bahwa tidak memengaruhi hasil KNN pada set fitur aktif.
